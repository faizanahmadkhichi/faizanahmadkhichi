# Poster Maker Pro — Product Brief

[Open Poster Maker Pro](https://faizankhichi.me/poster/)

## Overview

Poster Maker Pro is a browser-based visual workspace for producing social graphics and posters without requiring a conventional desktop design application.

## Product goals

- Make common design operations approachable from a browser.
- Provide a useful editing experience across desktop and mobile screens.
- Support flexible compositions instead of fixed, single-purpose templates.
- Let users export finished work for practical use.

## Selected capabilities

- Editable text and visual elements
- Backgrounds, stickers and reusable presets
- Layer-oriented composition controls
- Custom canvas sizes
- Export tools for social-media graphics

## Engineering considerations

Interactive design tools require careful state management, predictable layer behavior, responsive controls and export consistency. The interface adapts its working area and controls to the available screen size while preserving the composition.

## My role

Product architecture, interaction design, frontend engineering, responsive behavior and deployment.
